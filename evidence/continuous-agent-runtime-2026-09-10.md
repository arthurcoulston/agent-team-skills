# Reading — When Errors Become Narratives

[Source](https://arxiv.org/abs/2606.14589v1). Wu. Version 1, 2026-06-12.
Reading scope: abstract and version metadata only.

The abstract describes one personal-assistant agent runtime in continuous
production since March 2026, spanning roughly 40 scheduled jobs, eight model
providers, a tool-governance proxy, a knowledge-base memory plane, 4,286 unit
tests and 827 governance checks. It reports 22 incidents with root-cause
postmortems over eight weeks and highlights failures whose signals did not
reach a human in actionable form. This is evidence that a real long-lived
runtime can require repeated repair; it is not a demonstration of success at
a continuing mission.

## Limits

Only the abstract was read. This is one author-reported system, not an
independent deployment study; outside users and service-level outcomes are not
established. The incident count is an existence proof of failure shapes, not
an incidence rate transferable to other systems. No result was reproduced.
