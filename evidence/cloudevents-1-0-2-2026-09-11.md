# Reading — CloudEvents 1.0.2

CloudEvents separates event data from context. Its required source and id pair
identifies a distinct event and lets consumers recognize a retransmitted
duplicate; type and specversion support interpretation, while subject, time,
and dataschema can add routing and schema context.

The specification explicitly distinguishes the occurrence's source from the
producer that creates the event record, and an event does not identify a
routing destination. Event identity therefore aids provenance and duplicate
handling but is not proof of sender identity, authority, delivery, or truth.
