# Reading — Prompt Repetition Improves Non-Reasoning LLMs v1

[Source](https://arxiv.org/abs/2512.14982v1). Reading scope: Experimental setup, results and reasoning comparison; v1.

This study reports benefits from repeating prompts in several non-reasoning benchmark configurations. The experiments used an early-2025 model panel; the December paper date should not be mistaken for testing current September-2026 models. Results differ with reasoning configuration. The narrow lesson is that repetition is not intrinsically wasteful. This is not evidence to duplicate every standing instruction, nor to import the intervention without a relevant comparison.

This is a paraphrased reading record, not an independently reproduced result.
