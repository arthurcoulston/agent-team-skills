[Source](https://arxiv.org/abs/2602.11988v2). Reading scope: Abstract and previously reviewed experimental scope; v2.

In the studied coding setting, repository context files do not generally improve task resolution and increase cost. Instructions can elicit additional work without improving the benchmark outcome. This motivates testing both useful completion and procedural overhead. The evaluation concerns Python repository tasks; it does not measure all legitimate purposes of standing instructions. Deleting authority, privacy or other requirements because they lack a benchmark gain would exceed the finding.
