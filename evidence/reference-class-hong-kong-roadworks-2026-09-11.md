# Reading — compare a plan with outcomes from similar work

The paper reports reference-class forecasts for Hong Kong roadworks using a
dataset of 863 projects. Its method compares a proposed undertaking with the
actual outcomes of similar undertakings rather than relying only on a
project-specific inside view.

The abstract supports external base rates for forecast claims when a defensible
reference class exists. It does not address discovery of beneficiary needs, and
class selection can erase differences that matter. This is an abstract-only
reading and should not support claims about details of the study's method.
